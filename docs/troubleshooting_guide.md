# AIペルソナシステム トラブルシューティングガイド

## ユーザー向け（アプリケーション操作に起因する問題）

### ログインと権限の問題

#### 問題: ログイン後に「利用権限がまだありません」と表示される

**原因:** ロール（`admin` または `member`）がまだ付いていません。

**対処法:**
1. 管理者にロールを付けてもらう（管理者の手順は [利用者・ロール・グループの管理](user_management.md#ロールを付ける)）
2. ログアウトしてログインし直す

#### 問題: 「ログインの有効期限が切れました」と表示される

**原因:** 8 時間操作しなかったか、ログインから 7 日たちました。

**対処法:** もう一度ログインしてください。

#### 問題: ログインしようとすると 403 になる

**原因:** WAF を有効にしている環境で、同じ IP から短時間にログイン画面へのアクセスが集中しました。社内のネットワークなど、多くの人が同じ IP から使っていると起きることがあります。

**対処法:** 数分待ってからやり直す。続くときは管理者に連絡する（管理者は [CDK デプロイガイドの「運用（管理者向け）」](../cdk/README.md#ログインできない403-が出ると言われたら) を参照）。

#### 問題: 「試行回数が上限に達しました」と表示される（閉域構成）

**原因:** パスワードを続けて間違えたため、しばらくログインできなくなっています。

**対処法:** 時間をおいてからやり直す。パスワードを忘れた場合は、管理者に一時パスワードを設定してもらう（[閉域構成ガイドの「パスワードを忘れたとき」](closed_network.md#パスワードを忘れたとき)）。

#### 問題: 共有されたはずのものが「共有されたもの」に出ない

**対処法:**
1. 画面を再読み込みする
2. 共有先のグループに自分が所属しているか、管理者に確認する
3. 所有者に、共有先の設定を確認してもらう

それでも出ないときは、管理者が共有の索引を作り直します（[CDK デプロイガイドの「共有の索引の作り直し」](../cdk/README.md#共有の索引の作り直し)）。

#### 問題: 編集・削除のボタンがない、または「この操作の権限がありません」と表示される

**原因:** 共有されたものは、閲覧と利用だけができます。編集・削除・共有先の変更は、所有者と admin だけができます（[ユーザーガイドの「共有と権限」](user_guide.md#共有と権限)）。

#### 問題: ナレッジベースやデータセットに「〔利用権限なし〕」と表示される

**原因:** その資産の利用範囲に、自分のグループが入っていません。議論・インタビュー・アンケートでは使われません。

**対処法:** 使う必要があれば、admin に利用範囲へグループを足してもらう（[ユーザーガイドの「8.5 組織資産の利用範囲」](user_guide.md#85-組織資産の利用範囲)）。

### ファイルアップロードの問題

#### 対応ファイル形式一覧

| 用途 | 対応形式 | サイズ上限 |
|------|----------|-----------|
| ペルソナ生成 | `.txt`, `.md`, `.pdf`, `.docx`, `.doc`, `.csv` | 10MB |
| インタビュー（ファイル添付） | `.png`, `.jpg`, `.gif`, `.webp`, `.pdf`, `.txt`, `.csv`, `.html`, `.md` | 画像5MB / その他10MB |
| 議論ドキュメント | `.png`, `.jpg`, `.jpeg`, `.pdf` | 画像5MB / PDF 10MB / 合計32MB |
| ナレッジファイル | `.pdf`, `.docx`, `.pptx`, `.xlsx`, `.txt`, `.md` | 10MB |
| マーケットレポート | `.pdf`, `.docx`, `.doc`, `.txt`, `.md`, `.csv` | 10MB |
| アンケート画像 | `.png`, `.jpg`, `.jpeg` | 5MB |

#### 問題: ペルソナ生成用ファイルのアップロードが失敗する

**対処法:**
1. ファイル形式の確認
   - 対応形式: `.txt`, `.md`, `.pdf`, `.docx`, `.doc`, `.csv`
   - サイズ上限: 10MB
   - テキストファイルのエンコーディング: UTF-8、Shift_JIS、EUC-JP
   - PDF/DOCXはmarkitdownで自動変換

#### 問題: ナレッジファイルのアップロードが失敗する

**対処法:**
1. ファイル形式の確認
   - 対応形式: `.pdf`, `.docx`, `.pptx`, `.xlsx`, `.txt`, `.md`
   - サイズ上限: 10MB
2. ペルソナ詳細画面の「知識」タブからアップロードしているか確認

#### 問題: 議論用ドキュメントのアップロードが失敗する

**対処法:**
1. ファイル形式の確認
   - 対応形式: PNG, JPEG, PDF のみ
   - 個別ファイル: 画像5MB / PDF 10MB
   - 合計: 最大32MB（リクエストペイロード全体の上限）
2. ファイルの整合性確認
```bash
file --mime-type your_file.png
```

#### 問題: PDFドキュメントが正しく処理されない

**対処法:**
1. PDFが破損していないか確認
2. ページ数を確認（最大100ページ）
3. パスワード保護されていないか確認
4. テキストを含んでいるか確認（画像のみのPDFは非対応の場合あり）

### インタビューモードの問題

#### 問題: インタビューセッション作成エラー

**症状:**
- 「インタビューセッションの作成に失敗しました」エラー

**対処法:**
1. 最低1体のペルソナが選択されているか確認
2. ブラウザをリロードして再試行
3. 問題が続く場合は管理者に連絡（AWS認証情報の問題の可能性）

#### 問題: チャットの応答が返らない

**症状:**
- メッセージ送信後にローディングが終わらない
- 「ペルソナが回答を考えています...」が継続表示される

**対処法:**
1. ブラウザの開発者ツール（F12）でConsole/Networkタブを確認
2. ページをリロード（Cmd+Shift+R）
3. 問題が続く場合は新しいセッションを作成

#### 問題: セッション保存エラー

**対処法:**
1. セッション名が空でないか確認
2. メッセージが含まれているか確認（空のセッションは保存不可）

### マスアンケートの問題

#### 問題: アンケートが作成できない

**対処法:**
1. テンプレート名が空白のみになっていないか確認
2. 質問が1つ以上追加されているか確認
3. 選択式質問の場合、選択肢が2つ以上あるか確認
4. 画像は1枚まで添付可能

#### 問題: 対象ペルソナ数のエラー

**制限:**
- 最小: 10人以上
- 最大: 10,000人（画像付きの場合は1,000人まで）

画像付きアンケートでペルソナ数を増やしたい場合は、画像を削除してください。

なお最小10人は**入力欄の値だけでなく、フィルタ条件に実際に合致する人数**にも適用される。フィルタを絞りすぎて該当者が10人未満になった場合はアンケートを開始できない。「対象ペルソナをプレビュー」で該当人数を確認できる。

#### 問題: 「条件に合致するペルソナが…人しかいません」と表示される

**原因:**
フィルタ条件が厳しすぎて、アンケートに必要な10人分のデータが集まらない。

**対処法:**
1. フィルタ条件を緩める（年齢範囲を広げる、職業キーワードを外す等）
2. 「対象ペルソナをプレビュー」で該当人数を確認しながら調整する
3. カスタムデータセットを使っている場合は、データ自体が10件以上あるか確認する

#### 問題: 「データ件数が…件しかありません」と表示される

**原因:**
データセット自体の件数が最小件数に達していない。フィルタを指定していない状態でこのメッセージが出る場合、条件を緩めても解決しない。

**発生する場面:**
- CSVアップロード時（100件未満のデータセットは保存させない）
- 10件未満の既存データセットを選んでアンケートを開始したとき

**対処法:**
- 必要な件数以上のデータセットを選択する、またはデータを追加する

#### 問題: アンケートが「待ち」「実行中」のまま完了しない

アンケートは 1 件ずつ順番に実行する。前のアンケートが終わるまで、後のアンケートは「待ち」のまま待つ。

**対処法:**
1. 1,000人で数分、10,000人で十数分が目安です（並列数の既定 64 のとき）。ペルソナ数が多いほど時間がかかります
2. 実行は打ち切り時間（既定 2 時間）を過ぎるとエラーで終わります。それより長く「実行中」のままなら管理者に確認を依頼

#### 問題: CSVダウンロードが失敗する

**対処法:**
1. ダウンロードのボタンを押し直す（押すたびにアプリが権限を確かめ、新しいダウンロードを始めます）
2. 閉域構成で「ファイルが大きすぎるため表示できません」と出た場合は、CSV が 200 MiB を超えています。管理者に S3 からの取り出しを依頼する（[閉域構成ガイド](closed_network.md#大きなファイルのダウンロード)）

#### 問題: カスタムCSVのアップロードが失敗する

**対処法:**
1. CSVファイル形式の確認
   - UTF-8エンコーディング
   - ヘッダー行が存在すること
   - カンマ区切り
2. ファイルサイズ: 最大100MB
3. 特殊文字やエスケープの確認
```bash
head -5 your_file.csv
wc -l your_file.csv
```

#### 問題: インサイトレポートの生成に失敗する

**対処法:**
1. しばらく時間をおいて再試行（API制限の可能性）
2. 問題が続く場合は管理者に連絡

#### 問題: ペルソナ生成・レポート生成が「データ量が大きすぎて…」で失敗する

**症状:**
- 「生成するデータ量が大きすぎて処理しきれませんでした」
- 「分析対象のデータ量が大きすぎてレポートを生成しきれませんでした」

**原因:**
生成数や入力量が多く、1回の生成が出力トークン上限を超過している。

**対処法（ユーザー）:**
1. ペルソナ生成数を減らす、またはアップロードするファイルを小さくする
2. レポートの場合は分析対象を絞る、議論ログを短くする

**対処法（管理者）:**
- 環境変数 `AGENT_MAX_TOKENS`（既定 32000）で出力トークン上限を調整できる。
  多数の一括生成が常態化している場合は値を引き上げる。

### UI表示の問題

#### 問題: ページが更新されない

**症状:**
- ボタンをクリックしても反応がない
- フォーム送信後に画面が更新されない

**解決方法:**
1. ブラウザのキャッシュをクリア（Cmd+Shift+R）
2. ブラウザの開発者ツール（F12）でエラーを確認
3. htmxが読み込まれているか確認
```javascript
console.log(htmx.version);
```

#### 問題: リアルタイム表示（SSE）が動作しない

**症状:**
- 議論やインタビューのストリーミングが表示されない
- 接続エラーが表示される

**解決方法:**
1. ブラウザがSSEに対応しているか確認
```javascript
console.log('SSE supported:', typeof EventSource !== 'undefined');
```
2. プロキシやファイアウォールがSSE接続をブロックしていないか確認
3. ページをリロードして再試行

#### 問題: ストリーミング中に接続が切断される

**対処法:**
1. ネットワーク接続の安定性を確認
2. ページをリロードして再試行
3. プロキシ経由の場合は管理者にタイムアウト設定の確認を依頼

### 外部データセット連携の問題（実験的機能）

#### 問題: ペルソナがデータにアクセスできない

**対処法:**
1. ペルソナ詳細画面で紐付け設定を確認
2. 紐付けキー（user_id等）が正しいか確認
3. 議論/インタビュー開始時に「外部データセット連携を有効にする」がONか確認
4. 環境で `ENABLE_DATASET_ANALYSIS=false` になっていないか確認（既定は有効）
5. 不安定な場合はリトライ

### エラーメッセージ早見表（ユーザー向け）

> 画面に表示される文言は `web/error_messages.py` のカタログに集約されている。
> 文言を変更する場合はカタログ側を修正し、本表も合わせて更新すること。
> なお内部エラーに起因するもの（「〜の処理中にエラーが発生しました」）は、
> 原因の詳細をサーバーログにのみ出力する。調査時はログを参照する。

**表示のされ方** — エラーの性質によって出方が変わる。

| 性質 | 表示 | 入力内容 |
|---|---|---|
| 入力の誤り・量の超過 | 該当項目の横に赤字（フォームは残る） | **保持される** |
| 対象が見つからない・設定不備 | 領域を置き換えて表示（再試行/復帰リンク付き） | — |
| 再試行で解決しうる内部エラー | 画面右上のトースト通知 | **保持される** |
| 必須項目の未入力・型不正（「入力内容を確認してください」） | 画面右上のトースト通知 | **保持される** |

最後の1つだけトーストなのは、この検証がリクエスト受付時（フォームを特定できる
前）に行われるため。項目ごとの赤字表示ができないかわりに、画面を書き換えない
ことで入力を守っている。

「入力し直しになった」という報告があれば、その経路が上記のどれで表示されて
いるかを確認する（トーストが出ているなら入力は消えていない）。

#### 全画面共通

| エラーメッセージ | 原因 | 対処法 |
|---|---|---|
| 入力内容を確認してください | 必須項目の未入力や値の形式不正（サーバー側の受付時検証） | フォームの必須項目と入力形式を確認して再送信 |
| エラーが発生しました。時間をおいて再度お試しください。 | 種別を特定できない内部エラー | 時間をおいて再試行。詳細はサーバーログを参照 |
| **ページが見つかりません**（フルページのエラー画面） | 削除済み・存在しないID のURLに直接アクセスした | 画面の「一覧に戻る」から復帰する。ブックマークが古い可能性がある |

#### ファイル関連

| エラーメッセージ | 原因 | 対処法 |
|---|---|---|
| 許可されていないファイル形式です。対応形式: … | 非対応形式 | メッセージに表示された対応形式を使用。[対応形式一覧](#対応ファイル形式一覧)も参照 |
| ファイルサイズが制限を超えています。最大サイズ: …MB | サイズ上限超過 | ファイルサイズを削減、または添付数を減らす |
| ファイルが空です。 | 内容が空のファイル | 内容のあるファイルを選択 |
| ファイル内容が短すぎます。… | 分析に足る分量がない | より詳細な内容のファイルをアップロード |
| テキストファイルとして読み取れません。… | 非対応エンコーディング | UTF-8 / Shift_JIS / EUC-JP のいずれかで保存 |
| ファイル名に不正な文字が含まれています。 | パス区切り等を含むファイル名 | ファイル名を変更 |
| ファイルの処理中にエラーが発生しました。… | 内部エラー（S3/DB等） | 時間をおいて再試行。詳細はサーバーログを参照 |

#### AI生成関連

| エラーメッセージ | 原因 | 対処法 |
|---|---|---|
| 生成するデータ量が大きすぎて処理しきれませんでした | ペルソナ生成数・入力ファイル量が多く出力トークン上限を超過 | ペルソナ生成数を減らすか、アップロードするファイルを小さくして再試行 |
| 議論の実行中にエラーが発生しました | レート制限/APIエラー | 時間をおいて再試行 |
| 議論の開始中にエラーが発生しました | レート制限/APIエラー | 時間をおいて再試行。トースト通知で表示され設定内容は保持される |
| インサイトの再生成中にエラーが発生しました | データ不足/APIエラー | 議論内容を確認し再試行 |
| 分析対象のデータ量が大きすぎてレポートを生成しきれませんでした | 議論ログ・分析対象が多く出力トークン上限を超過 | 対象を絞るか、議論ログを短くして再試行 |

#### 議論・レポート関連

| エラーメッセージ | 原因 | 対処法 |
|---|---|---|
| 議論トピックが空です | トピック未入力 | トピックを入力 |
| 議論トピックが短すぎます。5文字以上で入力してください | トピックが5文字未満 | 5文字以上で入力 |
| 議論トピックが長すぎます。200文字以内で入力してください | トピックが200文字超 | 200文字以内に短縮 |
| 議論には最低2つのペルソナが必要です | 参加ペルソナが1つ以下 | ペルソナを2つ以上選択 |
| 議論参加ペルソナは最大5つまでです | 参加ペルソナが6つ以上 | 5つ以下に減らす |
| 重複したペルソナが含まれています | 同一ペルソナを複数選択 | 重複を解除 |
| ラウンド数は1以上で指定してください / 10以下で指定してください | ラウンド数が範囲外 | 1〜10で指定 |
| ドキュメントの合計サイズが制限を超えています（最大32MB） | 添付合計が32MB超 | ファイルを減らすかサイズを削減 |
| 選択されたモデルは利用できません。設定を確認してください | 未対応のmodel_id（フォーム改竄・古いUI等） | ページを再読み込みしてモデルを選び直す |
| 選択されたモデルは現在無効化されています。管理者に設定の有効化を依頼してください | 追加ペルソナベースモデル（GPT-5.6 Terra/Luna、Gemma 4 31B）を選択したが管理者が未有効化 | Claude系モデルに変更するか、管理者に有効化を依頼 |
| 選択したモデルの入力サイズ上限（最大…MB）を超えています。… | 選択モデル（Gemma 4 31B等）のリクエストサイズ上限を超過 | モデルを変更するか、添付ドキュメントを減らす |
| レポートは最大3件まで保存できます。不要なレポートを削除してください。 | 1議論あたりのレポート上限 | 既存レポートを削除してから保存 |
| レポートが見つかりません | 削除済み等でレポート不在 | 一覧を再読み込み |
| 議論の処理中にエラーが発生しました。… | 内部エラー | 時間をおいて再試行。詳細はサーバーログを参照 |
| 議論エージェントの準備に失敗しました。… | エージェント初期化の失敗 | 時間をおいて再試行。詳細はサーバーログを参照 |

> 上記のモデル関連エラーはインタビューモードでも文言に「インタビュー」が付いた同義の
> エラーが表示される（例:「選択したモデルは現在インタビューでのPDF等のドキュメント
> 添付に対応していません」）。原因・対処法は議論モードと同じ。

#### マスアンケート関連

| エラーメッセージ | 原因 | 対処法 |
|---|---|---|
| テンプレート名は空白のみでは登録できません | テンプレート名が空白 | 有効な名前を入力 |
| 質問が1つも含まれていません | 質問未追加 | 質問を1つ以上追加 |
| 選択式質問「…」には2つ以上の選択肢が必要です | 選択肢不足 | 選択肢を2つ以上追加 |
| 対象ペルソナ数は10以上で指定してください | ペルソナ数が10未満 | 10以上を指定 |
| 条件に合致するペルソナが…人しかいません。… | **フィルタ適用後**の該当者が10人未満 | フィルタ条件を緩める。プレビューで人数を確認 |
| データ件数が…件しかありません。… | **データセット自体**が下限未満（アンケートは10件、CSVアップロードは100件。フィルタでは解決しない） | 下限以上のデータセットを選択、またはデータを追加 |
| CSVファイルを読み取れませんでした。… | CSVの形式・エンコーディング不正 | UTF-8、カンマ区切り、ヘッダー行ありで保存 |
| CSVにデータ行がありません。 | ヘッダーのみのCSV | データ行を含むCSVを使用 |
| テキスト型のカラムが見つかりません。… | ペルソナ概要に使える列がない | マッピング画面で該当カラムを指定 |
| 回答の生成に失敗しました。… | Step Functions の実行が失敗・中止で終わった | 時間をおいてアンケートを作り直す。詳細はサーバーログを参照 |
| 回答の生成が制限時間内に終わりませんでした。… | 実行が打ち切り時間（既定 2 時間）を超えた | 対象ペルソナ数を減らすか、時間をおいて作り直す |
| …件中…件の回答を取得できなかったため、… | 取れなかった回答が 5% を超えた（または全員分取れなかった） | 時間をおいて作り直す。続く場合は管理者がスロットリングを確認 |
| この環境ではアンケートを実行できません。… | 実行基盤の設定（`SURVEY_STATE_MACHINE_ARN` など）がない | 管理者向け「[アンケート実行がエラーになる](#問題-アンケート実行がエラーになる)」を参照 |
| アンケートの実行基盤を利用できないため、… | 実行の開始・結果の読み取りが権限・設定の誤りで 30 分以上続けて失敗した | 管理者向け「[アンケート実行がエラーになる](#問題-アンケート実行がエラーになる)」を参照 |
| システムの切り替えでアンケートの実行が中断されました。… | バッチ推論の時代に実行中だったアンケート | アンケートを作り直す |
| 対象ペルソナ数は10000人までです | ペルソナ数が上限超過 | 10000以下を指定（画像付きの場合は1000まで） |
| 画像付きアンケートの場合、対象ペルソナ数は1000人までです | 画像付きで1000人超過 | 1000以下に減らすか画像を削除 |
| 画像は1枚まで添付できます | テンプレート画像数超過 | 画像を1枚に減らす |
| アンケートが見つかりません | 削除済み等でアンケート不在 | 一覧から選び直す |
| アンケート結果がまだ生成されていません | 実行が完了していない | 実行完了まで待つ |
| 抽出件数が少なすぎます（…件）。… | セグメント抽出の下限未満 | 抽出条件を緩める |
| 抽出件数が多すぎます（…件）。… | セグメント抽出の上限超過 | 抽出条件を絞る |

|---|---|---|

### マスアンケート（Step Functions）

アンケートは Web タスクの中の進行役が、待ちのアンケートを 1 件ずつ Step Functions のステートマシン
（Distributed Map）へ渡して実行する。ペルソナごとの推論（`bedrock:InvokeModel`）を呼ぶのは
Step Functions のサービス自身で、アプリは開始・確認・停止だけを行う。

#### 問題: アンケート実行がエラーになる

**症状:**
- ステータスが「エラー」になる
- 「この環境ではアンケートを実行できません」「アンケートの実行基盤を利用できない」エラー

**対処法:**
1. 実行基盤の設定の確認（CDK でデプロイした環境ではタスクに渡っている）
```bash
echo $SURVEY_STATE_MACHINE_ARN
echo $SURVEY_RUN_LEASE_TABLE_NAME
```
   - 手元では空のままが既定で、アンケートは実行しない

2. ステートマシンの実行の確認（実行の名前はアンケートの ID）
```bash
aws stepfunctions list-executions --state-machine-arn $SURVEY_STATE_MACHINE_ARN --max-results 5
aws stepfunctions describe-execution --execution-arn <execution-arn>
```

3. ペルソナ数の確認
   - 最低10人以上が必要
   - 画像付きの場合は最大1000人、画像なしの場合は最大10000人

4. モデルアクセスの確認
   - アンケートのモデル（既定: Claude Haiku 5.5、`SURVEY_MODEL_ID`）が使えるか確認

#### 問題: アンケートが「待ち」「実行中」のまま完了しない

**対処法:**
1. サーバーログで進行役のイベントを確認する（`survey.run_started`・`survey.run_completed`・
   `survey.runner_waiting`・`survey.runner_round_failed`・`survey.runner_lease_lost`）
2. 「待ち」のままなら、前のアンケートが実行中か、進行役が動いていない（`SURVEY_STATE_MACHINE_ARN` が空、
   または担当の記録を取れていない）
3. 「実行中」のままなら、上の `describe-execution` で実行の状態を確認する。打ち切り時間（既定 2 時間）を
   過ぎると Step Functions が実行を止め、アプリはエラーにする

#### 問題: ペルソナデータセットの読み込みが遅い

**対処法:**
1. 初回はHugging FaceからダウンロードしParquet形式でS3に配置するため30-120秒かかります
2. 2回目以降はS3上のParquetに直接クエリするため高速です
3. S3接続・AWS認証情報が有効か確認
4. DuckDB/Polarsがインストールされているか確認
```bash
uv run python -c "import duckdb; import polars; print('OK')"
```

### 長期記憶（AgentCore Memory）

#### 問題: 長期記憶が動作しない

アプリは起動するときに AgentCore Memory の設定を読み込みます。読み込めないと、長期記憶を無効にして起動します。

**対処法:**
1. アプリのログで、起動時のメッセージを確認する
   - `AgentCore Memory strategies resolved` が出ていれば、読み込めています
   - `AgentCore Memory strategy lookup failed (...); long-term memory is disabled` が出ていれば、読み込めずに無効になっています。括弧の中の例外名（`AccessDeniedException` など）で原因を調べます
2. Memory の ID を確認する。AWS では Data スタックの出力 `AgentCoreMemoryId` にあります

   ```bash
   aws cloudformation describe-stacks --stack-name AIPersonaDev-Data --region ap-northeast-1 \
     --query "Stacks[0].Outputs[?OutputKey=='AgentCoreMemoryId'].OutputValue" --output text
   ```

3. ローカルでは `.env` の `ENABLE_LONG_TERM_MEMORY=true`、`AGENTCORE_MEMORY_ID`、`AGENTCORE_MEMORY_REGION` を確認する

### ログの確認方法

#### AWS環境

1. クラスター名とサービス名を、App スタックの出力 `ClusterName`・`ServiceName` で確認する（閉域構成はスタック名が `AIPersonaDevClosed-App`）

   ```bash
   aws cloudformation describe-stacks --stack-name AIPersonaDev-App --region ap-northeast-1 \
     --query "Stacks[0].Outputs[?OutputKey=='ClusterName' || OutputKey=='ServiceName'].[OutputKey,OutputValue]" --output text
   ```

2. AWSコンソール → ECS → そのクラスター → サービス →「ログ」タブでコンテナログを確認する
3. タスクが起動しないときは、同じサービスの「イベント」タブで原因を確認する

ログは CloudWatch Logs に 30 日間残ります。

エラー発生時刻を絞り込んで検索するとトラブルシューティングが効率的です。

#### ローカル環境

```bash
# デバッグモードで起動
uv run uvicorn web.main:app --reload --log-level debug
```
